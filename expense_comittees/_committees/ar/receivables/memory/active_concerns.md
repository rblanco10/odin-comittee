## Update Instructions

### Raising a Concern

1. Add to appropriate priority section
2. Use ID format: `CONCERN-NNN`
3. Assign owner (usually the critic who raised it)
4. Set status to `RAISED`

### Updating a Concern

1. Update status as it progresses
2. Add notes on progress
3. Move between priority sections if escalated/de-escalated

### Resolving a Concern

1. Move to "Recently Resolved" section
2. Document resolution
3. Remove from open concerns
