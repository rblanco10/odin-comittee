# Handoff Templates

> **For**: All Committee Members  
> **Purpose**: Standard phrases for transferring discussion between members

---

## Why Handoffs Matter

Explicit handoffs ensure:
1. **Clarity**: Everyone knows who is speaking next
2. **Record**: Transcript shows intentional flow
3. **Respect**: Speakers are properly introduced
4. **Focus**: Discussion stays organized

---

## Basic Handoff Templates

### Template 1: Simple Yield

Use when transferring to a specific member for their expertise:

```
"I now yield to [Full Name], [Role], who can address [specific topic]."
```

**Examples**:
- "I now yield to Marcus Chen, Marqeta Expert, who can address the card token lifecycle."
- "I now yield to Dr. Sarah Park, Security Adversary, who has raised a concern about this approach."

---

### Template 2: Question Handoff

Use when posing a specific question to another member:

```
"I have a question for [Full Name], [Role]: [Question]?"
```

**Examples**:
- "I have a question for James Wright, Ash Framework Expert: How does this interact with Ash policies?"
- "I have a question for Elena Rodriguez, Failure Advocate: What's the failure mode here?"

---

### Template 3: Expertise Request

Use when you need specific expertise you don't have:

```
"This requires expertise in [area]. I request input from [Full Name], [Role]."
```

**Examples**:
- "This requires expertise in SOAP protocol handling. I request input from David Kim, WEX Expert."
- "This requires expertise in financial reconciliation. I request input from Linda Tran, Financial Reconciliation Expert."

---

### Template 4: Challenge Invitation

Use when inviting a critic to challenge:

```
"Before we proceed, I invite [Full Name], [Role], to challenge this proposal."
```

**Examples**:
- "Before we proceed, I invite Dr. Eleanor Vance, Complexity Critic, to challenge this proposal."
- "Before we proceed, I invite Michael Torres, Scalability Skeptic, to challenge this proposal."

---

### Template 5: Discussion Return

Use when returning to a previous speaker:

```
"Returning to [Full Name], [Role], to continue on [topic]."
```

**Examples**:
- "Returning to Rachel Kim, Checkbook Expert, to continue on the webhook retry logic."
- "Returning to Alex Chen, Reactor Patterns Expert, to continue on the compensation flow."

---

### Template 6: Chair Intervention

Used by Chair to redirect or manage:

```
"Chair intervention: [Full Name], [Role], please address [specific point]."
```

**Examples**:
- "Chair intervention: Pattern Historian, please provide context on how we handled this before."
- "Chair intervention: Security Adversary, we need your assessment before proceeding."

---

## Research Handoff Templates

### Template 7: Research Assignment

Use when requesting research:

```
"I request Research Clerk to investigate [topic] in [location/scope]."
```

**Examples**:
- "I request Research Clerk to investigate the webhook event types in `ember_payments/webhooks/webhook_handler.ex`."
- "I request Research Clerk to investigate how PayoutBatch connects to PayoutItem across the codebase."

---

### Template 8: Research Initiation (by Research Clerk)

Used by Research Clerk when beginning research:

```
"This is [Name], Research Clerk. I am now researching [topic] in [location]. 
I will report findings when complete."
```

**Examples**:
- "This is Maria Santos, Research Clerk. I am now researching the circuit breaker configuration in `services/payments_circuit_breaker.ex`. I will report findings when complete."

---

### Template 9: Research Report

Used by Research Clerk when reporting findings:

```
"This is [Name], Research Clerk, reporting on [topic].

**Location**: [file path(s)]
**Findings**: [summary]
**Relevant Code**: [brief excerpt or line numbers]

I now yield back to [requesting member/Chair]."
```

---

## Historian Handoff Templates

### Template 10: Historical Context Request

Use when past decisions may be relevant:

```
"I request historical context from [Historian Role] on [topic]."
```

**Examples**:
- "I request historical context from Pattern Historian on similar adapter abstractions."
- "I request historical context from Debt Archaeologist on why this code exists."

---

### Template 11: Historical Context Provision

Used by historians when providing context:

```
"This is [Name], [Historian Role]. Regarding [topic]:

**Relevant History**: [context]
**Past Decisions**: [if any]
**Patterns Observed**: [if applicable]

This context suggests [implication]. I yield back."
```

## Critic Handoff Templates

### Template 12: Challenge Declaration

Used by critics when raising concerns:

```
"This is [Name], [Critic Role]. I challenge this proposal on [grounds]:

**Concern**: [specific concern]
**Risk**: [what could go wrong]
**Question**: [question that must be answered]

I await a response."
```

**Example**:
```
"This is Dr. Eleanor Vance, Security Adversary. I challenge this proposal 
on credential handling grounds:

**Concern**: The OAuth tokens are being stored in plain text in the connection record.
**Risk**: Database breach exposes all provider credentials.
**Question**: Why are we not using encrypted storage via Cloak?

I await a response."
```

---

### Template 13: Challenge Resolution

Used when responding to a challenge:

```
"Responding to [Critic Name]'s challenge on [topic]:

**Response**: [address the concern]
**Mitigation**: [how the risk is handled]
**Evidence**: [code reference or reasoning]

I believe this addresses the concern. [Critic Name], is this satisfactory?"
```

## Session Flow Templates

### Template 14: Opening Handoff (by Chair)

```
"This session is now open. I call upon [Full Name], [Role], to begin with [topic]."
```

---

### Template 15: Topic Transition (by Chair)

```
"We have concluded discussion on [topic A]. We now move to [topic B].
I call upon [Full Name], [Role], to lead this discussion."
```

---

### Template 16: Decision Call (by Chair)

```
"Discussion appears complete. I call for a decision on [specific matter].
[Full Name], [Role], as the proposer, please restate the proposal clearly."
```

---

### Template 17: Closing Handoff (by Chair)

```
"We are now closing this session. 
Session Historian, please provide the summary.
Artifacts Clerk, please confirm all outputs are captured."
```

---

## Special Situation Templates

### Template 18: Disagreement Acknowledgment

```
"I hear the disagreement between [Member A] and [Member B] on [topic].
Let me summarize both positions:
- [Position A]: [summary]
- [Position B]: [summary]

[Next action: vote, table, escalate, etc.]"
```

---

### Template 19: Human Director Deference

```
"This matter requires Human Director input. 
[Full Name], Human Director, we request your guidance on [specific question].

Options as we see them:
1. [Option A]
2. [Option B]
3. [Option C]"
```

---

### Template 20: Emergency Escalation

```
"CHAIR EMERGENCY: I am escalating [issue] for immediate attention.
All other discussion is suspended.
[Relevant experts], please focus on this immediately."
```
