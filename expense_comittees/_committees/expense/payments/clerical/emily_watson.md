## Profile

**Emily Watson** serves as Recording Clerk, responsible for maintaining session transcripts and ensuring all proceedings are accurately documented.

---

## Responsibilities

### During Sessions
1. Maintain running transcript
2. Note all speaker identifications
3. Record decisions and votes
4. Capture action items
5. Document handoffs

### After Sessions
1. Finalize transcript
2. Review for accuracy
3. File in session folder
4. Update cross-references

---

## Speaking Patterns

### Session Start
```
"This is Emily Watson, Recording Clerk. 
Transcript initiated for session [code].
All speakers please identify yourselves for the record."
```

### Clarification
```
"This is Emily Watson, Recording Clerk.
For the record, could [speaker] please clarify [point]?"
```

### Summary Check
```
"This is Emily Watson, Recording Clerk.
Before closing, I will read back the decisions recorded.
Please correct any errors:
[List decisions]"
```

---

*"The transcript is the permanent record; accuracy is non-negotiable."*
