# Technical Terms Glossary

---

## Elixir/OTP Terms

| Term | Definition |
|------|------------|
| **GenServer** | Generic server process |
| **Supervisor** | Process that manages other processes |
| **Agent** | Simple state container process |
| **BEAM** | Erlang virtual machine |

---

## Ash Framework Terms

| Term | Definition |
|------|------------|
| **Resource** | Data model with actions and policies |
| **Action** | Operation on a resource (CRUD + custom) |
| **Policy** | Authorization rule |
| **Domain** | Group of related resources |
| **Reactor** | Multi-step workflow engine |
| **Change** | Modification applied during action |

---

## API Terms

| Term | Definition |
|------|------------|
| **REST** | Representational State Transfer |
| **SOAP** | Simple Object Access Protocol |
| **OAuth** | Authorization framework |
| **HAL** | Hypertext Application Language (Dwolla) |
| **WS-Security** | Web Services Security (WEX) |

## Payment Processing Terms
