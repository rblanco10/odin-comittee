# Handoff Templates

> **For**: All Committee Members  
> **Purpose**: Standard phrases for transferring discussion

---

## Yielding to Another Member

### After Completing Your Point
```
"I yield to [Name], [Role], who can speak to [specific aspect]."

Example:
"I yield to Robert Chen, Infrastructure Tier Expert, who can speak to 
the implications for infra_payments."
```

### When You Lack Expertise
```
"This is outside my area — I defer to [Name], [Role], on this matter."

Example:
"This is outside my area — I defer to Dr. Priya Sharma, Testing Specialist, 
on the implications for our test strategy."
```

### Requesting Counter-Argument
```
"I'd like to hear from [Name], [Role], on potential concerns with this approach."

Example:
"I'd like to hear from Dr. Reginald Thornbury, Architecture Critic, 
on potential concerns with this approach."
```

## Chair Handoff Templates

### Opening Discussion
```
"Let's begin with [Name], [Role], to present [topic]."

Example:
"Let's begin with Victoria Castellanos, AR Product Specialist, 
to present the customer management domain model."
```

### Redirecting Discussion
```
"Let me bring in [Name], [Role], to address [specific point]."

Example:
"Let me bring in Dr. William Chang, Ash Framework Expert, 
to address how we should model state machines in this context."
```

### Requesting Synthesis
```
"[Name], [Role], can you synthesize what we've discussed about [topic]?"

Example:
"Gregory Hayes, Session Historian, can you synthesize what we've 
discussed about the tier classification rules?"
```

### Inviting Challenge
```
"I'd like our critics to weigh in. [Name], [Role], do you see issues 
with this proposal?"

Example:
"I'd like our critics to weigh in. Professor Miranda Okonkwo, 
Complexity Critic, do you see issues with this proposal?"
```

## Research Handoff Templates

### Requesting Research
```
"[Research Clerk], please examine [file/pattern/code] and report findings."

Example:
"David Okonkwo, Research Clerk, please examine the existing ember_payments 
structure and report on adapter patterns."
```

### Presenting Research
```
"This is [Name], [Role]. I've examined [file/code] and found [findings]."

Example:
"This is David Okonkwo, Research Clerk. I've examined the infra_payments 
dependency graph and found 3 concerning upward dependencies..."
```

## Decision Handoff Templates

### Proposing Decision
```
"Based on our discussion, I propose we decide: [decision statement]"

Example:
"Based on our discussion, I propose we decide: product_receivables 
will NOT depend on product_payables; shared logic goes in domain_coding."
```

### Recording Decision
```
"This is [Recording Clerk]. I am recording decision [ID]: [statement]"

Example:
"This is Emily Chen, Recording Clerk. I am recording decision 
DEC-2026-01-08-001: Tier-prefixed naming convention is required for 
all apps in the umbrella."
```

### Closing Topic
```
"Decision recorded. Moving to [next topic]. [Name], [Role], please lead."

Example:
"Decision recorded. Moving to infrastructure tier planning. Robert Chen, 
Infrastructure Tier Expert, please lead."
```

## Human Director Handoff Templates

### Yielding to Human Director
```
"Human Director, we've [summarized finding]. Would you like to [ask/proceed]?"

Example:
"Human Director, we've identified 5 apps for the core tier. 
Would you like us to proceed with defining their interfaces?"
```

### After Human Director Input
```
"Thank you, Human Director. Based on your guidance, we will [action]."

Example:
"Thank you, Human Director. Based on your guidance, we will prioritize 
the AR product and defer Treasury to a later phase."
```

### Requesting Human Input
```
"Human Director, we have a question requiring your decision: [question]"

Example:
"Human Director, we have a question requiring your decision: 
Should we proceed with the umbrella scaffold now, or first complete 
the full member roster?"
```

## Subcommittee Handoff Templates

### Delegating to Subcommittee
```
"This requires deeper investigation. I'm referring this to [Subcommittee] 
led by [Lead Name]."

Example:
"This requires deeper investigation. I'm referring this to the 
Migration Subcommittee led by Carlos Rivera."
```

### Subcommittee Reporting
```
"This is [Name], [Subcommittee Lead]. Our subcommittee has concluded: 
[findings/recommendations]"

Example:
"This is Carlos Rivera, Migration Subcommittee Lead. Our subcommittee 
has concluded: ember_payments can be migrated to infra_payments with 
minimal breaking changes using our adapter shim approach."
```

---

## Emergency Handoffs

### Urgent Issue
```
"URGENT: [Name], [Role], please immediately address [issue]."

Example:
"URGENT: Sebastian Volkov, Performance Critic, please immediately 
address the N+1 query issue discovered in the invoice listing."
```

### Pausing for Critical Matter
```
"I need to pause our current discussion. [Critical matter description]"

Example:
"I need to pause our current discussion. The Human Director has 
provided new guidance that affects our approach."
```

---

*"Clean handoffs maintain momentum; clumsy ones create confusion."*
