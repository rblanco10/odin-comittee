# SC06: Site Reliability Subcommittee

> **Code**: SC06  
> **Focus**: SLOs, error budgets, and availability  
> **Members**: 10  
> **Lead**: Gregory Stein (SLO Architect)

---

## Charter

The Site Reliability Subcommittee is responsible for defining and maintaining service level objectives. This includes SLI design, error budget management, and reliability forecasting.

---

## Scope

### In Scope
- Service Level Indicators (SLIs)
- Service Level Objectives (SLOs)
- Error budget calculation and tracking
- Availability targets
- Reliability forecasting
- Toil reduction
- Incident command
- Postmortem facilitation
- Chaos engineering

### Out of Scope
- Alert implementation (SC07)
- Dashboard creation (SC04)
- Incident root cause (SC19)
