# SC09: Performance Engineering Subcommittee

> **Code**: SC09  
> **Focus**: Profiling, bottleneck detection, and baselines  
> **Members**: 9  
> **Lead**: James Wright (Bottleneck Detective)

---

## Charter

The Performance Engineering Subcommittee is responsible for performance analysis and optimization. This includes profiling, bottleneck detection, baseline establishment, and performance testing.

---

## Scope

### In Scope
- Bottleneck detection
- Flame graph analysis
- Memory profiling
- GC impact analysis
- I/O wait investigation
- Concurrency optimization
- Hot path identification
- Baseline establishment

### Out of Scope
- Metric design (SC02)
- Dashboard creation (SC04)
- Capacity planning (SC17)
