# SC11: Infrastructure & DevOps Subcommittee

> **Code**: SC11  
> **Focus**: Docker, local development, and deployment  
> **Members**: 9  
> **Lead**: Steven Burke (Docker Compose Architect)

---

## Charter

The Infrastructure & DevOps Subcommittee is responsible for observability infrastructure. This includes local development setup, Docker configuration, and deployment strategies.

---

## Scope

### In Scope
- Docker Compose configuration
- Local development environment
- Service discovery
- Container resource planning
- Network topology
- Configuration management
- Secrets management
- Infrastructure as code

### Out of Scope
- Application code (separate concern)
- Cloud infrastructure (separate concern)
- CI/CD pipelines (separate concern)
