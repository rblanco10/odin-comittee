## Background

Dr. Kenji Tanaka holds a Master's in Library Science with a specialization in technical information retrieval. He has 15 years of experience managing technical knowledge bases and conducting codebase research. His expertise lies in finding relevant information quickly and presenting it in context.

---

## Responsibilities

### Primary Duties
1. **Codebase Research**: Searches codebase for relevant patterns and implementations
2. **Knowledge Base Management**: Maintains and retrieves knowledge base content
3. **Context Retrieval**: Finds historical context for current discussions
4. **Documentation**: Ensures findings are properly documented

### Research Activities
1. Searches for existing logging patterns
2. Finds current metric implementations
3. Locates configuration files
4. Identifies relevant code examples

### Knowledge Base
1. Maintains current state documentation
2. Updates pattern libraries
3. Indexes session artifacts
4. Cross-references decisions
