## Pattern Template

Each pattern should include:

```markdown
## Pattern: [Name]

### Problem
What problem does this pattern solve?

### Solution
How does this pattern solve it?

### Example

```elixir
# Code example
```

### Rationale
Why is this the right approach?

### When to Use
When should this pattern be applied?

### When NOT to Use
When should this pattern be avoided?

### Related Patterns
What other patterns relate to this one?

### Anti-Patterns
What approaches should be avoided?
```

## Pattern Categories

### Logging Patterns
- Structured logging
- Correlation ID propagation
- Log level usage
- Error logging
- Async logging

### Metric Patterns
- Counter usage
- Gauge usage
- Histogram usage
- Label design
- Naming conventions

### Tracing Patterns
- Span creation
- Context propagation
- Attribute naming
- Sampling
- Error recording

### Error Handling Patterns
- Error logging
- Error metrics
- Error tracing
- Error correlation

## Anti-Patterns

Anti-patterns are approaches that should be avoided. Each anti-pattern should include:

- What it is
- Why it's problematic
- What to do instead
