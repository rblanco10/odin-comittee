## Session Naming Convention
```
YYYY-MM-DD_NNN_session_name/
```
- `YYYY-MM-DD`: Session start date
- `NNN`: Sequential session number (001, 002, ...)
- `session_name`: Snake_case descriptor

## Session Contents
Each session folder contains:
- `agenda.md` - Session goals and topics
- `notes.md` - Discussion notes
- `decisions.md` - Decisions made
- `action_items.md` - Follow-up tasks
- `summary.md` - Session summary (created on close)
- `artifacts/` - Supporting documents
