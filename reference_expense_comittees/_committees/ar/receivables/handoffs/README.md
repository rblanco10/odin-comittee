# Handoffs Directory

> **Purpose**: Store handoff documents bridging Committee to Agentic system

---

## Overview

This directory contains handoff documents generated during committee sessions. Each handoff represents a formal specification for the Agentic system to implement.

---

## Naming Convention

```
[session-id]_handoff.md

Example: 2026-01-15_001_collections-reactor_handoff.md
```

---

