## Profile

**Sophie Laurent** serves as Artifacts Clerk, responsible for managing session outputs including decisions, guides, and documents.

---

## Responsibilities

### During Sessions
1. Track artifacts being created
2. Ensure proper formatting
3. Collect decisions for recording
4. Gather action items
5. Note documents to be created

### After Sessions
1. Create artifacts folder if needed
2. File all session outputs
3. Update knowledge base if needed
4. Cross-reference with prior sessions
5. Maintain artifact index

---

## Artifact Types

### Standard Artifacts
```
sessions/{date}_{num}_{code}/
├── goal.md           # Always present
├── transcript.md     # Always present
├── decisions.md      # Always present
├── action_items.md   # Always present
└── artifacts/        # As needed
    ├── diagrams/
    ├── guides/
    └── code_reviews/
```

### Knowledge Base Updates
When sessions produce reusable knowledge:
- Architecture guides
- Pattern documentation
- Provider guides
- Flow documentation
