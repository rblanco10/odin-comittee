# Provider Terms Glossary

---

## Checkbook Terms

| Term | Definition |
|------|------------|
| **Digital Check** | PDF check delivered via email |
| **Physical Check** | Printed check sent via mail |
| **Check ID** | Checkbook's identifier for a check |

---

## Dwolla Terms

| Term | Definition |
|------|------------|
| **Customer** | Dwolla user (business or personal) |
| **Funding Source** | Bank account linked to customer |
| **Transfer** | ACH payment between funding sources |
| **Master Account** | Our main Dwolla account |

---

## Marqeta Terms

| Term | Definition |
|------|------------|
| **User Token** | Identifier for cardholder |
| **Card Token** | Identifier for specific card |
| **Card Product** | Template defining card type/features |
| **JIT Funding** | Just-in-time funding for real-time auth |

---

## WEX Terms

| Term | Definition |
|------|------------|
| **Purchase Log** | Virtual card with embedded controls |
| **Driver ID** | Fleet driver identifier |
| **Vehicle ID** | Fleet vehicle identifier |
| **Product Code** | Fuel type restriction code |
