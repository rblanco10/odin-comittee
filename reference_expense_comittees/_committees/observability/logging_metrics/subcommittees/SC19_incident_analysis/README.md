## Charter

The Incident Analysis Subcommittee is responsible for learning from incidents. This includes root cause investigation, timeline reconstruction, and systemic issue identification.

---

## Scope

### In Scope
- Root cause investigation
- Timeline reconstruction
- Contributing factor analysis
- Systemic issue identification
- Blameless culture advocacy
- Action item tracking
- Recurrence prediction

### Out of Scope
- Incident response (SC06)
- Alert design (SC07)
- SLO management (SC06)

## Key Questions

1. What was the root cause?
2. What was the timeline?
3. What factors contributed?
4. Is this a systemic issue?
5. How do we prevent recurrence?
6. What action items are needed?

---

## Postmortem Template

1. **Summary**: What happened
2. **Timeline**: When things happened
3. **Root Cause**: Why it happened
4. **Contributing Factors**: What made it worse
5. **Impact**: What was affected
6. **Detection**: How we found out
7. **Resolution**: How we fixed it
8. **Action Items**: What we'll do differently
9. **Lessons Learned**: What we learned
