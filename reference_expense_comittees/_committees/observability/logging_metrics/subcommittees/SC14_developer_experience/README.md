# SC14: Developer Experience Subcommittee

> **Code**: SC14  
> **Focus**: Logging APIs, documentation, and ergonomics  
> **Members**: 8  
> **Lead**: Dr. William Chang (Logging API Designer)

---

## Charter

The Developer Experience Subcommittee is responsible for making observability easy to use. This includes API design, documentation, debugging workflows, and copy-paste patterns.

---

## Scope

### In Scope
- Logging API design
- Documentation
- Debug workflow optimization
- Onboarding guides
- Ergonomics evaluation
- Copy-paste patterns
- Error message design
- Developer tooling

### Out of Scope
- Logging implementation (SC01)
- Metrics implementation (SC02)
- Infrastructure (SC11)

## Developer Experience Principles

1. **Easy to do the right thing**
2. **Hard to do the wrong thing**
3. **Copy-paste should work**
4. **Documentation at point of use**
5. **Errors should guide to solutions**
