## Charter

The Standards & Governance Subcommittee is responsible for observability standards. This includes naming conventions, schema management, deprecation coordination, and cross-team standardization.

---

## Scope

### In Scope
- Naming conventions
- Schema evolution management
- Deprecation coordination
- Cross-team standardization
- Documentation enforcement
- Exception approval

### Out of Scope
- Implementation details (various SCs)
- Infrastructure (SC11)
- Specific patterns (SC01, SC02, SC03)
