# SC15: Cost Optimization Subcommittee

> **Code**: SC15

> **Members**: 7  
> **Lead**: Jonathan Blake (Log Volume Auditor)

---

## Charter

The Cost Optimization Subcommittee is responsible for managing observability costs. This includes log volume auditing, storage cost forecasting, and ROI analysis.

---

## Scope

### In Scope
- Log volume auditing
- Storage cost forecasting
- Query cost analysis
- Retention ROI calculation
- Sampling economics
- Infrastructure rightsizing
- Cost attribution

### Out of Scope
- Retention policies (SC10)
- Infrastructure sizing (SC11)
- Metric design (SC02)

1. What's our current log volume?
2. What's the storage cost projection?

5. Are we rightsized for our volume?
6. What's the cost per query?
