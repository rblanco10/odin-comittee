# SC04: Grafana & Visualization Subcommittee

> **Code**: SC04  
> **Focus**: Dashboards, panels, and Grafana provisioning  
> **Members**: 11  
> **Lead**: Dr. William Park (Dashboard Architect)

---

## Charter

The Grafana & Visualization Subcommittee is responsible for designing and maintaining dashboards. This includes dashboard architecture, panel design, query optimization, and dashboard-as-code provisioning.

---

## Scope

### In Scope
- Dashboard architecture and organization
- Panel design and layout
- PromQL and LogQL query design
- Variable and template design
- Dashboard provisioning (as code)
- Annotation strategies
- Grafana plugins
- Dashboard performance

### Out of Scope
- Alert rules (SC07)
- Metric design (SC02)
- Log format (SC01)
