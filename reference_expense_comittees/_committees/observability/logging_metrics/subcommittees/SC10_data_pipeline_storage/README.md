## Charter

The Data Pipeline & Storage Subcommittee is responsible for observability data storage and lifecycle. This includes time-series database optimization, retention strategies, and data compaction.

## Scope

### In Scope
- Time-series database optimization
- Log retention strategies
- Query performance optimization
- Data compaction
- Index strategies
- Cold storage planning
- Data lifecycle management
- Storage cost optimization

### Out of Scope
- Metric design (SC02)
- Log format (SC01)
- Dashboard queries (SC04)
