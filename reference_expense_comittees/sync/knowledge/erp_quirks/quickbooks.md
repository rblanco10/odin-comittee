## Key Differences from Other ERPs

### Simpler Model
QBO is designed for SMBs, which means:
- No multi-subsidiary
- Flat class structure (optional)
- Limited custom fields
- Simpler overall data model

This simplicity can be a "quirk" when trying to map enterprise concepts.
