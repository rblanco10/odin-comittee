## Session Naming Convention

Sessions are named using the format: `[target-name]_[YYYY-MM-DD]`

Examples:
- `ky-core_2026-02-04`
- `auth-service_2026-02-05`
- `user-api_2026-02-06`

## How to Use

### Starting a New Session
Use `/cc-session-open` with a target file or folder.

### Checking Session Status
Use `/cc-session-status` to see current session state.

### Resuming a Paused Session
Use `/cc-session-resume [session-id]` to continue a paused session.

### Listing All Sessions
Use `/cc-session-list` to see all sessions.
