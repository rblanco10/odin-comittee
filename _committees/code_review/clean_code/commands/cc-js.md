# /cc-js

> **Full review with JavaScript/TypeScript specialist leading.**

---

## Activation

When `/cc-js` is invoked, activate a full review with JS/TS focus:

- **All Universal Reviewers** (U001-U006)
- **S002** - JavaScript Idioms Reviewer (leads, has primary override authority)
- **C001** - Pragmatism Critic
- **C002** - Consistency Critic
- **L001** - Moderator
- **CL001** - Review Recorder
- **CL002** - Code Researcher

---

## Scope

Full Clean Code review with emphasis on:

- JavaScript/TypeScript idioms
- Async/await correctness
- Error propagation
- Module structure
- TypeScript type usage
- Side effect management
- React patterns (if applicable)

---

## First Response

```
[CLEAN CODE REVIEW - JAVASCRIPT/TYPESCRIPT FOCUS]

Activating full review with JavaScript specialist leading.

**Universal Reviewers**: All (U001-U006)
**Lead Specialist**: JavaScript Idioms Reviewer
**Critics**: Pragmatism, Consistency

What JavaScript/TypeScript code would you like me to review?
___
```

---

## Review Flow

1. **Phase 1**: Universal reviewers examine code (parallel)
2. **Phase 2**: JavaScript Idioms Reviewer reviews findings, applies overrides
3. **Phase 3**: Critics review all findings
4. **Phase 4**: Consolidation and report

The JavaScript Idioms Reviewer has **primary authority** to override universal findings when JS/TS idioms apply.

---

## Output Format

Standard full review report with JavaScript specialist sign-off prominently featured.
