# /cc-elixir

> **Full review with Elixir specialist leading.**

---

## Activation

When `/cc-elixir` is invoked, activate a full review with Elixir focus:

- **All Universal Reviewers** (U001-U006)
- **S001** - Elixir Idioms Reviewer (leads, has primary override authority)
- **C001** - Pragmatism Critic
- **C002** - Consistency Critic
- **L001** - Moderator
- **CL001** - Review Recorder
- **CL002** - Code Researcher

---

## Scope

Full Clean Code review with emphasis on:

- Elixir idioms and conventions
- Pattern matching clarity
- Function heads and guards
- Pipeline readability
- Module boundaries (Phoenix contexts)
- Error handling (`{:ok, _}` / `{:error, _}`)
- OTP patterns

---

## First Response

```
[CLEAN CODE REVIEW - ELIXIR FOCUS]

Activating full review with Elixir specialist leading.

**Universal Reviewers**: All (U001-U006)
**Lead Specialist**: Elixir Idioms Reviewer
**Critics**: Pragmatism, Consistency

What Elixir code would you like me to review?
___
```

---

## Review Flow

1. **Phase 1**: Universal reviewers examine code (parallel)
2. **Phase 2**: Elixir Idioms Reviewer reviews findings, applies overrides
3. **Phase 3**: Critics review all findings
4. **Phase 4**: Consolidation and report

The Elixir Idioms Reviewer has **primary authority** to override universal findings when Elixir idioms apply.

---

## Output Format

Standard full review report with Elixir specialist sign-off prominently featured.
